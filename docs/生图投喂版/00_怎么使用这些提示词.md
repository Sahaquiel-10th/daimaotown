# 呆猫折纸拼贴小镇：生图投喂说明

这套文档专门用于直接复制给做图 AI，不是设计规范。

## 最重要的规则

1. 不要再上传前两张“完整小镇微缩模型图”作为参考。
2. 不要让做图 AI 生成完整地图。
3. 每次只生成一个建筑或一组简单道具。
4. 第一张先生成“项目工坊风格锚点”。
5. 选定风格锚点后，后续每一次生成都上传这张锚点图。
6. 提示词不要自行追加“更精致、更多细节、电影感、真实质感”等词。
7. 图片里不生成中文招牌，所有文字由网页后加。

## 推荐窗口分工

- 窗口 A：只做风格锚点和冒险家公会。
- 窗口 B：做项目建筑。
- 窗口 C：做技能摊位和环境道具。

窗口 B、C 开始前，都要先上传窗口 A 最终选定的项目工坊图片。

## 生成顺序

1. 打开 `01_风格锚点与冒险家公会.md`。
2. 从零生成项目工坊，不上传任何参考图。
3. 生成 2～4 次，选一张最接近“数字剪纸游戏素材”的。
4. 把选中的图片保存为 `project-workshop-anchor-v01.png`。
5. 上传这张图片，再生成冒险家公会。
6. 项目工坊和公会都确认后，才开始其他两个文档。

## 怎样判断项目工坊合格

- 一眼看上去是 2D 游戏素材，不是实体模型照片。
- 是等距俯视角度，不是正面建筑插画。
- 建筑完整、居中、背景简单。
- 轮廓简单，缩小后仍然能认出来。
- 奶油墙面、深色屋顶、少量黄色点缀。
- 没有人物、树木、道路、文字和完整场景。

如果连续四次仍然偏向实体模型，不要继续加长提示词。把最好的一张发回主任务，我们针对那一张做一次单点编辑。

## 后续提示词中的“参考图”

文档里凡是出现：

> 使用我上传的参考图

指的都是最终选定的 `project-workshop-anchor-v01.png`，不是之前生成的完整小镇图。
