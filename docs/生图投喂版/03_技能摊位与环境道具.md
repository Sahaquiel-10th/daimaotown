## C4. 第一组环境道具

这一张允许生成一组物品：

```text
Use the uploaded project-workshop image as the visual style reference.

Create a clean game-asset sheet containing exactly six separate small environment props for the same isometric web game:
1. one blank town notice board,
2. one folded-paper street lamp,
3. one simple bench,
4. one mailbox,
5. one stack of parcels,
6. one small planter.

Match the reference image's 2D digital cut-paper collage style, paper texture, orthographic isometric camera, simple lighting, and restrained cream, charcoal, warm-yellow (#FFD76B), and pale-green (#BFE7C0) palette.

Arrange the six objects in a clean 3-by-2 grid on a plain warm light-gray background. Keep every object fully separated with generous space and no overlap.

No characters, no scenery, no road, no readable text, no numbers, no logo, no cast shadows.
```
